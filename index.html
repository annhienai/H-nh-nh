Cấu Trúc Website, Lưu Trữ Đám Mây & Hướng Dẫn Triển Khai

1. Tổ Chức Thư Mục Chuẩn GitHub Pages
thu-vien-ai-an-nhien/
├── index.html               # Giao diện chính
├── CNAME                    # Tên miền riêng
├── css/
│   └── exhibition.css       # Hệ thống giao diện
├── js/
│   ├── cloud-storage.js     # Kết nối Đám mây
│   └── gallery-app.js       # Xử lý Thư viện & Admin
├── data/
│   └── gallery-catalog.json # Cơ sở dữ liệu ảnh
└── assets/
    └── images/
        ├── originals/       # Ảnh gốc chất lượng cao
        └── thumbnails/      # Ảnh thu nhỏ tốc độ cao

Website hoạt động hoàn hảo ở cả 2 chế độ: Single-File độc lập và Cấu trúc thư mục chuẩn GitHub Pages.

2. Phương Án Lưu Trữ Ảnh Thực Tế & Bền Vững
  • • Tầng 1 – Cloudinary CDN (Miễn phí 25GB): Lưu trữ file ảnh gốc & tự động tạo ảnh thu nhỏ (Thumbnail WebP/AVIF) siêu tốc qua API trực tiếp đã tích hợp sẵn trong khu Quản trị.
  • • Tầng 2 – Đồng bộ GitHub Repository API / Firebase / Supabase: Khi thêm/sửa/xóa tác phẩm trong mục Quản trị, hệ thống tự động đẩy file data/gallery-catalog.json lên kho lưu trữ đám mây để mọi khách truy cập đều thấy ngay lập tức.
  • • Tầng 3 – IndexedDB Dung Lượng Lớn: Cơ sở dữ liệu bền vững ngay trên thiết bị, không bị giới hạn 5MB như bộ nhớ tạm thông thường.
3. Hướng Dẫn Vận Hành & Đưa Lên Tên Miền Riêng
  1. Đăng nhập Quản trị: Nhấn nút Quản Trị Viên (Mật khẩu mặc định: AnNhien2026!) để tải nhiều ảnh lên cùng lúc, sửa thông tin, sắp xếp thứ tự hoặc đổi mật khẩu.
  2. Kết nối Cloudinary (Tùy chọn): Nhập Cloud Name và Upload Preset trong tab Đám Mây để ảnh tải lên được lưu trữ vĩnh viễn trên CDN quốc tế.
  3. Triển khai GitHub Pages: Tải bộ mã nguồn lên Repository GitHub → Vào Settings → Pages → Chọn nhánh main.
  4. Gắn tên miền riêng: Trỏ 4 bản ghi A về IP GitHub Pages và điền tên miền (VD: trienlam.annhienai.vn) vào mục Custom Domain.
